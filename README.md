# diskPelada
Projeto Engenharia de Software 2026.1

Sistema de distribuição e acesso a quadras e peladas de Futebol

- Para executar o backend suba o container docker na raiz do projeto:

``` bash
docker-compose up -d

```
- Caso não ocorra erros execute o projeto maven

``` bash
cd api
mvn spring-boot:run
```
Chave de api publica / privada temporária para desenvolvimento
